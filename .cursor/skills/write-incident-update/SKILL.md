# Write incident update

Use only cited facts; write `unknown` for gaps. Include incident, status,
absolute window, monitor ID, release/time, featured request, symptom,
hypothesis, evidence, and next approval needed. Keep it under 12 lines. Draft
or sandbox only: do not mention channels broadly and never send without
explicit approval and a named sandbox destination.
